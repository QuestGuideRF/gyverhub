# GyverHub

Библиотека для создания панелей управления для Arduino-совместимых микроконтроллеров. Позволяет создавать графические интерфейсы управления устройствами через веб-приложение или нативные приложения, поддерживает интеграцию с системами умного дома.

## Краткое описание

GyverHub — это платформа, состоящая из библиотеки для устройства (Arduino-совместимого микроконтроллера) и приложения для управления. Библиотека позволяет программно создавать интерфейсы управления, которые автоматически отображаются в клиентском приложении. Устройство и приложение обмениваются данными по собственному протоколу через различные интерфейсы связи.

## ✨ Особенности

- **Конструктор интерфейса** — программное создание панели управления с более чем 30 виджетами
- **Множество способов связи** — MQTT, HTTP/WebSocket, Serial, Bluetooth BLE, Telegram
- **Поддержка различных платформ**:
  - ESP8266 и ESP32 — нативная поддержка WiFi для работы по HTTP/WS/MQTT
  - Любые Arduino — работа в ручном режиме через любой способ связи
- **Интеграция с умным домом** — автоматический парсинг данных для MQTT (Яндекс Алиса, Home Assistant и др.)
- **Автоматическое обнаружение устройств** в сети
- **Полная кастомизация** — создание собственных виджетов, подключение скриптов и стилей
- **Дополнительные модули**:
  - Сенсорный графический дисплей (Canvas)
  - Менеджер файлов
  - Информация об устройстве
  - OTA обновление
  - Проверка обновлений на GitHub
  - Защита паролем
  - Командная строка
- **1000 FontAwesome иконок** для оформления
- **Тёмная и светлая темы**, несколько цветовых схем, мультиязычный интерфейс
- **Полностью автономная работа** — не требует собственного сервера и "личного кабинета"
- **OTA обновление** проектов с GitHub, прошивка из браузера по USB

## 🚀 Быстрый старт

### Установка

#### Arduino IDE

1. Откройте Arduino IDE
2. Перейдите в **Скетч → Подключить библиотеку → Управлять библиотеками...**
3. Найдите "GyverHub" в поиске
4. Нажмите **Установить**

Библиотека автоматически установит все необходимые зависимости:
- `pubsubclient` (для MQTT)
- `arduinoWebSockets` (для WebSocket)
- `StringUtils`
- `GSON`
- `Pairs`

#### PlatformIO

Добавьте в файл `platformio.ini`:

```ini
lib_deps =
    GyverLibs/GyverHub
    GyverLibs/StringUtils
    GyverLibs/Pairs
    GyverLibs/GSON
    knolleary/PubSubClient
    links2004/WebSockets
```

### Настройка

#### Минимальный пример

```cpp
#include <GyverHub.h>

GyverHub hub("MyDevices", "ESP8266", "f6ad");  // имя сети, имя устройства, иконка

// Функция сборки интерфейса
void build(gh::Builder& b) {
    // Здесь создаются виджеты панели управления
}

void setup() {
    Serial.begin(115200);

#ifdef GH_ESP_BUILD
    // Подключение к WiFi
    WiFi.mode(WIFI_STA);
    WiFi.begin("SSID", "PASSWORD");
    while (WiFi.status() != WL_CONNECTED) {
        delay(500);
        Serial.print(".");
    }
    Serial.println();
    Serial.println(WiFi.localIP());

    // Настройка MQTT (опционально)
    hub.mqtt.config("test.mosquitto.org", 1883);
#endif

    hub.onBuild(build);  // Подключаем функцию сборки интерфейса
    hub.begin();         // Запускаем систему
}

void loop() {
    hub.tick();  // Вызываем тикер в главном цикле
}
```

#### Настройка WiFi

Для ESP8266/ESP32 можно использовать стандартное подключение к роутеру:

```cpp
WiFi.mode(WIFI_STA);
WiFi.begin("SSID", "PASSWORD");
while (WiFi.status() != WL_CONNECTED) {
    delay(500);
}
```

Или режим точки доступа:

```cpp
WiFi.mode(WIFI_AP);
WiFi.softAP("My Device");
```

#### Настройка MQTT

```cpp
// Базовый вариант (без авторизации)
hub.mqtt.config("test.mosquitto.org", 1883);

// С авторизацией
hub.mqtt.config("m8.wqtt.ru", 13448, "user", "pass");

// По IP адресу
hub.mqtt.config(IPAddress(12, 34, 56, 78), 1883);
```

#### Настройка Serial/Bluetooth

```cpp
// Для Serial
hub.stream.config(&Serial, gh::Connection::Serial);

// Для Bluetooth через SoftwareSerial
SoftwareSerial bt(3, 4);
hub.stream.config(&bt, gh::Connection::Bluetooth);
```

### Запуск

1. Загрузите прошивку на устройство
2. Откройте клиентское приложение (веб-версия, нативное приложение или вебморда ESP)
3. Введите имя сети, указанное в коде (`"MyDevices"` в примере выше)
4. Запустите поиск устройств или подключитесь напрямую

## 🛠 Использование

### Создание виджетов

В функции `build()` создаются виджеты панели управления:

```cpp
void build(gh::Builder& b) {
    // Кнопка
    if (b.Button().label("Включить").click()) {
        Serial.println("Кнопка нажата!");
    }

    // Слайдер с переменной
    static int value = 50;
    b.Slider(&value).label("Яркость").range(0, 100);

    // Переключатель
    static bool state = false;
    b.Switch(&state).label("Режим");

    // Поле ввода
    static String text = "";
    b.Input(&text).label("Текст");

    // Отображение значения
    b.Display(value).label("Текущее значение");
}
```

### Обновление виджетов

```cpp
void loop() {
    hub.tick();

    // Обновление виджета по имени
    static gh::Timer tmr(1000);
    if (tmr) {
        hub.update("display").value(millis());
    }
}
```

### Обработка действий

```cpp
void build(gh::Builder& b) {
    static int slider;

    // Способ 1: проверка click()
    if (b.Button().click()) {
        // Действие
    }

    // Способ 2: подключение флага
    bool flag = false;
    b.Button().attach(&flag);
    if (flag) {
        // Действие
    }

    // Способ 3: подключение функции-обработчика
    b.Button().attach(buttonHandler);
}
```

### Контейнеры и компоновка

```cpp
void build(gh::Builder& b) {
    // Горизонтальный контейнер
    if (b.beginRow()) {
        b.Button().size(2);  // ширина 2
        b.Button().size(1);  // ширина 1
        b.endRow();
    }

    // Вертикальный контейнер
    if (b.beginCol()) {
        b.Button();
        b.Button();
        b.endCol();
    }
}
```

Более подробные примеры находятся в папке `examples/`.

## 🧪 Технологии

### Поддерживаемые платформы

- **ESP8266** (v3.1.2+)
- **ESP32** (v2.0.14+, включая S2, S3, C3)
- **AVR** (Arduino Uno, Nano и др.)
- Другие Arduino-совместимые платформы

### Зависимости

- `PubSubClient` — для работы с MQTT
- `arduinoWebSockets` — для WebSocket соединений
- `StringUtils` — утилиты для работы со строками
- `GSON` — парсинг JSON
- `Pairs` — работа с парами ключ-значение

### Способы связи

- **MQTT** — через Интернет (любой MQTT брокер)
- **HTTP + WebSocket** — в локальной WiFi сети
- **Serial** — по USB или Bluetooth Serial
- **Bluetooth BLE** — через Bluetooth Low Energy модули
- **Telegram** — через телеграм-ботов

## 🔧 Конфигурация компиляции

Перед подключением библиотеки можно настроить её поведение через дефайны:

```cpp
// Отключение модулей связи
#define GH_NO_STREAM  // отключить Stream
#define GH_NO_HTTP    // отключить HTTP (для ESP)
#define GH_NO_WS      // отключить WebSocket (для ESP)
#define GH_NO_MQTT    // отключить MQTT (для ESP)

// Настройки
#define GH_BRIDGE_AMOUNT 5       // количество мостов подключения
#define GH_WS_PORT 81            // WebSocket порт
#define GH_HTTP_PORT 80          // HTTP порт
#define GH_MQTT_RECONNECT 10000  // период переподключения MQTT

// Отключение модулей
#define GH_NO_PAIRS    // отключить поддержку типа Pairs
#define GH_NO_INFO     // отключить info билдер
#define GH_NO_MODULES  // отключить "модули"

// Файловая система (для ESP)
#define GH_NO_FS                 // отключить файловую систему
#define GH_FETCH_CHUNK_SIZE 512  // размер чанка при скачивании
#define GH_UPL_CHUNK_SIZE 512    // размер чанка при загрузке

// Вебморда ESP
#define GH_FILE_PORTAL     // загружать сайт из памяти ESP
#define GH_INCLUDE_PORTAL // включить сайт в память программы (~50кБ)

#include <GyverHub.h>
```

## 🔄 Обновление

Рекомендуется регулярно обновлять библиотеку для получения исправлений и новых возможностей.

**Через Arduino IDE:**
1. Откройте менеджер библиотек
2. Найдите GyverHub
3. Нажмите "Обновить"

**Вручную:**
1. **Удалите** папку со старой версией библиотеки
2. Установите новую версию на место старой

> ⚠️ Важно: не заменяйте файлы напрямую — удаляйте старую версию перед установкой новой, так как в новых версиях могут удаляться файлы, которые останутся при замене.

Подпись относится к текущей версии проекта.
